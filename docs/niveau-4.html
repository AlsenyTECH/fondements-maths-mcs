Niveau 4 · Les applications

Les branches spécialisées

Ici chaque branche est un cours du master. Elles sont indépendantes les unes des autres, mais elles reposent toutes sur les niveaux 1 à 3.

1

Lis la fiche d'en-tête. Elle dit ce qu'il faut savoir avant, et ce que le nœud ouvre.

2

Refais les démonstrations sur une feuille, sans regarder.

3

Fais tourner le code. Python pour construire, SageMath pour vérifier.

4

Valide le nœud avec le bouton du bas. Ta progression est gardée sur cet appareil.
